# 🛒 Nepali Mart — E-commerce Website

Nepal's Largest Online Grocery Store. A multi-vendor e-commerce platform connecting local vendors, big marts, and mini marts directly with customers across Nepal.

## 🎯 Features

### 👤 Customer
- ✅ Register / Login
- ✅ Browse Products (Category, Search, Sort)
- ✅ Product Detail with Related Products
- ✅ Add to Cart
- ✅ Checkout (COD, eSewa, Khalti)
- ✅ Order History
- ✅ Profile

### 🏪 Vendor (Salesman)
- ✅ Register with Payment Info (eSewa, Khalti, Bank)
- ✅ Add Products (Image Upload)
- ✅ View Own Products
- ✅ View Orders
- ✅ Sales Dashboard

### 🔐 Admin
- ✅ Dashboard (Stats: Users, Products, Orders, Revenue)
- ✅ Manage Users (Approve/Delete)
- ✅ Manage Products (Approve/Delete)
- ✅ Manage Orders (Update Status)
